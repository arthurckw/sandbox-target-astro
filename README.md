# GrandJury Public Site (Astro)

## Overview

This is the **public-facing marketing site** for GrandJury, built with Astro for optimal SEO and fast page loads.

- **Tech Stack:** Astro 5.0 + Tailwind CSS + TypeScript
- **Purpose:** Landing pages, docs, blog - all SEO-optimized static HTML
- **Design System:** Unified with React platform (dark theme, teal accent)

---

## 🚀 Quick Start

### Development
```bash
cd astro-site
npm run dev
# Opens http://localhost:4321
```

### Build
```bash
npm run build
# Output: astro-site/dist/
```

## ✍️ **For Content Team: How to Add New Pages**

### Option 1: Simple Page (Astro)

**When to use:** Static content pages (About, Features, Pricing)

**Steps:**
1. Create `/src/pages/features.astro`:
```astro
---
import BaseLayout from '../layouts/BaseLayout.astro';
---

<BaseLayout
  title="Features - GrandJury"
  description="Powerful AI evaluation features for ML teams"
>
  <main class="max-w-7xl mx-auto px-4 py-20">
    <h1 class="text-4xl font-bold text-primary mb-6">
      Features
    </h1>

    <p class="text-lg text-secondary">
      Your content here...
    </p>
  </main>
</BaseLayout>
```

2. Build and deploy - it's live at `/features`!

---

### Option 2: Markdown Content (Recommended)

**When to use:** Documentation, blog posts, content that updates frequently

**Steps:**

1. **Create markdown file:** `/src/content/docs/getting-started.md`
```markdown
---
title: "Getting Started"
description: "Learn how to use GrandJury"
---

# Getting Started

Your markdown content here...

## Step 1: Sign Up

Create your account...

## Step 2: Create Evaluation

Follow these steps...
```

2. **Create template page:** `/src/pages/docs/[...slug].astro`
```astro
---
import { getCollection } from 'astro:content';
import BaseLayout from '../../layouts/BaseLayout.astro';

export async function getStaticPaths() {
  const docs = await getCollection('docs');
  return docs.map(doc => ({
    params: { slug: doc.slug },
    props: { doc }
  }));
}

const { doc } = Astro.props;
const { Content } = await doc.render();
---

<BaseLayout title={doc.data.title}>
  <article class="max-w-4xl mx-auto px-4 py-20 prose prose-invert">
    <Content />
  </article>
</BaseLayout>
```

3. **Configure content schema:** `/src/content/config.ts`
```typescript
import { defineCollection, z } from 'astro:content';

const docs = defineCollection({
  type: 'content',
  schema: z.object({
    title: z.string(),
    description: z.string(),
    author: z.string().optional(),
    publishDate: z.date().optional(),
  }),
});

export const collections = { docs };
```

## 🔍 SEO Best Practices

### Page Meta Tags
```astro
---
import BaseLayout from '../layouts/BaseLayout.astro';
---

<BaseLayout
  title="Your Page Title (50-60 chars)"
  description="Your meta description (150-160 chars) with keywords"
>
  <!-- Your content -->
</BaseLayout>
```

### Open Graph Images
Place images in `/public/og/` and reference:
```astro
<BaseLayout
  title="Features"
  description="..."
  ogImage="/og/features.png"
>
```

### Structured Data (JSON-LD)
```astro
<script type="application/ld+json">
{
  "@context": "https://schema.org",
  "@type": "WebPage",
  "name": "GrandJury Features",
  "description": "AI evaluation features..."
}
</script>
```

## 📊 Adding to Netlify Deployment

### After adding new pages, update `/netlify.toml`:

```toml
# Add your new public routes
[[redirects]]
  from = "/features"
  to = "/features.html"
  status = 200

[[redirects]]
  from = "/pricing"
  to = "/pricing.html"
  status = 200

[[redirects]]
  from = "/docs/*"
  to = "/docs/:splat.html"
  status = 200
```

## ❓ Common Questions

**Q: How do I add a new page?**
A: Create `src/pages/pagename.astro` - it becomes `/pagename` automatically

**Q: Can I use React components?**
A: Yes! Install `@astrojs/react` and import React components in `.astro` files

**Q: How do I preview changes before deploying?**
A: Run `npm run dev` locally - changes appear instantly

**Q: What's the difference between `/pages` and `/content`?**
A: `/pages` = page templates (code), `/content` = markdown content (easy editing)
